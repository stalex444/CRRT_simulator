# CRRT Practice Simulator

An interactive educational simulator for Continuous Renal Replacement Therapy (CRRT).

## Features

- 8 Clinical Scenarios (Hyperkalemia, Cardiorenal Syndrome, Citrate Toxicity, etc.)
- Real-time Filtration Fraction Analysis
- Drug Dosing Calculator
- Quiz Mode
- Filter Change Procedure Trainer
- Animated Circuit Visualization
- Pressure Monitoring

## For Educational Use Only

This simulator is designed for medical education and training purposes. It is not intended for clinical decision-making.

## Deployment

This project is configured for deployment on Render, Vercel, or Netlify.

### Build Command
```
npm install && npm run build
```

### Publish Directory
```
dist
```
